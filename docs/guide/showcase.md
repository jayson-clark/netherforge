# The showcase

`examples/showcase` in the NetherForge repository is a tour of everything the
engine does. Open it in the editor (with `examples/library`, the package it
depends on, next to it, where its `netherforge.json` finds it), start the dev
server, and join: you arrive at the hub of an expo, with an avenue running south
and a booth on each side every few steps. Each booth shows one feature: a title
over the entrance, a panel on the back wall saying what the feature is and which
files make it, the exhibits themselves, and a caption beside each one saying
what it shows and how it's done. Most exhibits are interactive: click them, or
press the button on a kiosk.

Everyone who joins is handed a **Tour guide** compass. Right-click it (or type
`/tour`) for a menu of every booth and world, ticked as you see them; `/expo`
brings you back to the hub from anywhere. A boss bar names the booth you stand
in, the sidebar counts how many you've seen, and stepping into every one earns
**The Grand Tour**, an advancement with a criterion per booth.

The dev server's main world is generated by the project (`terrain/plaza.json`, a
flat plaza), so a server whose world was made before needs it deleted once
(stop the server, remove its world, start again) for the expo to have its
ground.

## How it's put together

`modules/expo` lays the expo out: the order of the booths, the floor and walls
each gets, the title, panel and captions, kiosks, which booth a player is in,
the tour menu and the way to other worlds and back. Each booth is a module of its
own in `modules/(booths)/<id>_booth`, which calls `expo.booth({ ... })` with its
title, its panel and a `build` function that puts its exhibits in. Saving a
booth's module builds that booth again, so an edit shows at once; the exhibits
are temporary centities, gone with the module that made them.

The worlds beyond the avenue are `netherforge.json`'s `worlds`: `hills` (the
ruby hills terrain at 448 blocks tall, from `dimension_types/deep.json`), `sky`
(the sky islands, with their own dimension type) and `lobby`, a world the
project manages. The pocket world is one a script makes and deletes.

`tests/` runs on a fake server with the whole project loaded: every booth builds
without an error, the tour advancement has a criterion for each booth, and the
altar, greeter and settings do what they say.

## The library

`examples/library` is a [package](../format/packages.md) the showcase depends on
by path, and what a reusable library looks like: an exported `greetings` module
(which reads the library's own setting), an exported gem item with its own
script, a `gems` loot table, and the root advancement of a tab other projects
add to. The showcase's packages booth uses all four; nothing in the library
knows about the showcase.
